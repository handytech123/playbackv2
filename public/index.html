Quick Start

  1. Open the app and check that the top status shows the audio engine is ready.
  2. Use an empty setlist slot or the plus button to choose songs from the library.
  3. Review each song in Edit mode if cues, regions, key, BPM, pad, or arrangement need changes.
  4. Press Confirm Set. This builds the playback-ready cache and locks the set for live use.
  5. Switch to Performance mode and run the set from the transport, song tiles, or stage remote.

The app is designed so Dropbox and source song folders are not touched during live playback. Live playback uses the prepared app cache.

Weekly Workflow

  1. At home, refresh the library after metadata or song folders change.
  2. Build the setlist left to right.
  3. Edit song maps, cue markers, key changes, BPM changes, pads, and arrangements as needed.
  4. Confirm the set after edits are done.
  5. Use File > Export Set Package to create a transfer package.
  6. At church, use File > Import Set Package, then confirm and test audio routing.

Set packages carry the setlist and app metadata. They do not include the original multitrack WAV library.

Library And Metadata

The library reads song folders under the configured library folder. A song must have trusted metadata before it appears as usable in the setlist.

  • Library folder: set in Settings > Library.
  • Song facts: title, key, BPM, time signature, WAV count, and duration come from song metadata.
  • Grid: built from BPM, time signature, duration, and start time 0.000.
  • Skipped folders: folders missing required metadata are listed instead of silently guessed.

Refreshing the library reloads metadata and reflects analyzer changes. It should not invent missing song facts.

Setlist

The setlist is built left to right. Empty slots show a plus button. Filled slots show title, key, BPM, readiness, and song actions.

  • Drag a song tile to reorder it.
  • Dropping onto another song moves the existing song down when possible.
  • Use the remove button on a tile to clear that slot.
  • Transition tiles between songs control what happens after the previous song ends.

The app defaults to ten possible setlist slots, with only filled slots used for live playback.

Confirm Set

Confirm Set is the live readiness step. It prepares cached audio, writes the playback manifest, and marks the set ready for Performance mode.

  • Use it after adding songs, changing arrangements, changing keys, changing BPM, changing pads, or editing transitions.
  • If the set changes after confirmation, confirm again before live use.
  • Performance mode expects the confirmed set to be the source of truth.

Edit Mode

Edit mode is where song-specific work happens. Changes apply to the setlist song and its app metadata, not the original Dropbox WAV stems.

  • Use the waveform timeline to inspect song structure.
  • Use snap mode for measures, beats, or free movement.
  • Edit cue and region names from the lists below the waveform.
  • Change key, dynamic pad, BPM, and time signature from the editor panel.
  • Use Save Draft or Approve Cue/Regions when the song map is ready.

Arrangement Editing

Arrangement edits create a changed version of the song for this set. They are separate from approved cue and region metadata.

  • Split At Playhead: cuts the selected region at the current transport point.
  • Delete Selection: removes the selected cue or region object.
  • Remove + Close Gap: removes a song section and pulls later audio earlier.
  • Trim Start / Trim End: removes silence or extra audio at the beginning or end.
  • Undo Edit: steps backward through recent edit moves.
  • Save Arrangement: commits the current arrangement for the setlist song.

After an arrangement edit, the waveform and grid should redraw to match the new song length.

Performance Mode

Performance mode is the live operator surface. The song map is locked, but live actions remain available.

  • Transport controls remain active.
  • Mixer faders remain active.
  • Repeat, loop, jump, skip, cue next, pad, and panic are live controls.
  • Song edits are blocked until returning to Edit mode.

Transport

  • Play: starts from the current playhead in Edit mode or selected song in Performance mode.
  • Pause: stops audio movement without resetting the playhead.
  • Stop: stops playback and resets live state.
  • Return To Start: moves the playhead to song start without starting playback.
  • Spacebar: toggles play and pause while keeping click/cue/pad state in sync.

Measure 1 beat 1 is always time 0.000. The grid is the timing authority.

Repeat, Loop, Jump, And Skip

Live structure commands wait for musical boundaries. The app does not instantly jump in the middle of a section unless a feature is explicitly designed to do that.

  • Repeat 1: repeats the current region once, then continues.
  • Loop: repeats the selected region until the operator chooses the next action.
  • Jump: schedules a move to a chosen section.
  • Skip: passes to the next planned section.
  • Repeat and jump cues are scheduled ahead of the boundary so the band hears where the song is going.

Panic Recovery

Panic is a musical recovery mode, not a stop button.

  • Backing tracks fade down quickly.
  • Click and timing stay alive.
  • Dynamic pad starts in the song key.
  • The timeline keeps moving internally.
  • Automatic cues and slide MIDI are suppressed while panic is active.
  • Exit panic releases at a safe musical boundary, normally the next region.
  • Recovery should cue the band for the region being recovered to before tracks fade back in.

Dynamic Click, Cue, And Pad

The playback grid owns timing. Analyzer metadata provides song facts; the app places click, cue, and pad on the grid.

  • Dynamic Click: uses app-owned global click pattern WAVs, not song click stems.
  • 4/4: one measure has four grid beats.
  • 6/8, 9/8, 12/8: worship BPM is treated as dotted-quarter BPM; the grid still displays every eighth-note beat in the measure.
  • Dynamic Cue: plays matching cue phrase WAVs from the dynamic cue folder.
  • Dynamic Pad: uses the selected song key or manually selected pad file.

Mixer

The mixer controls live playback volume and signal visibility.

  • Music stems appear as channel strips.
  • Dynamic Click, Dynamic Cue, and Dynamic Pad are always available as dynamic tracks.
  • IEM sends are for music stems only, not click, cues, or dynamic pads.
  • Faders adjust live volume.
  • Meters update during playback so you can see signal activity.
  • Use the collapse and resize controls to balance mixer space against waveform space.

Audio And Dante Routing

Audio device selection lives in Settings > Audio. Routing lives in Settings > Routing.

  • Choose the default audio device in Settings and save it.
  • Use Refresh Audio Devices when Windows devices change.
  • Use Stereo for basic testing on local speakers or a two-channel interface.
  • Use Dante routing when Dante Virtual Soundcard is available on the playback computer.
  • The routing matrix assigns tracks, click, dynamic cue, pads, and IEM to output channels.

ProPresenter MIDI

The app can send a MIDI note to ProPresenter when cue markers are crossed.

  1. Create or choose a Windows MIDI path that ProPresenter can receive from, such as loopMIDI for the same computer or rtpMIDI for network use.
  2. In ProPresenter, configure MIDI input and map the note to the slide command you want.
  3. In this app, open Settings > Playback.
  4. Enable Send ProPresenter Slide MIDI.
  5. Refresh MIDI devices and select the ProPresenter MIDI output.
  6. Set channel, note, velocity, and note length.
  7. Press Test Next Slide.

During playback, the app sends the note once per cue marker. Panic suppresses slide MIDI so the operator can recover without unwanted slide movement.

Stage Remote

The remote is for live control from the stage or another device on the local network.

  • Open Settings > Remote to see available remote URLs.
  • Use the local network URL on a phone or tablet connected to the same network.
  • The remote shows setlist, current song, waveform, regions, and live action buttons.
  • Remote and main app should stay visually synced through playback state updates.

Exporting To The Church PC

Use set packages to move weekly work from the home computer to the playback computer.

  • Export Set Package: writes the current setlist and app metadata to a single package file.
  • Import Set Package: loads that work on the church computer.
  • After import, confirm the set and test audio output before rehearsal.
  • The church computer still needs access to the same song library folder structure.

Troubleshooting

  • No audio device: refresh audio devices, select the correct Windows/ASIO/Dante device, save settings, and restart if needed.
  • Song missing: refresh library and check that song metadata exists in the song folder.
  • Grid looks wrong: check BPM and time signature first. The app grid starts at 0.000.
  • Dynamic click sounds wrong: check the global click-pattern WAV for that time signature.
  • Cues or regions are off: verify the analyzer metadata and then reload app data.
  • Pad key wrong: check the song key and the selected dynamic pad in Edit mode.
  • ProPresenter not moving: refresh MIDI devices, verify the selected output, test the note, and confirm ProPresenter is listening to the same MIDI path.
